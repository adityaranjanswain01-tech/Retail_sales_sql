Project Overview

This project analyzes retail sales data with SQL to understand customer behavior, category performance and monthly sales trends. It covers everything from basic aggregations to advanced window functions.

Objectives
Understand sales patterns by gender, age and category.
Identify high-value and frequent customers.
Measure each category's contribution to total revenue.
Track monthly sales trends and month-over-month change.
